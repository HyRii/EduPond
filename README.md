# EduPond — a pond of knowledge

### Full-Stack Education Platform

EduPond is a full-stack education platform designed to provide an
integrated learning experience for students and educators.

The platform connects students, instructors, and administrators through
course management, learning progress, course requests, instructor
proposals, and learning-focused features.

---

## 🚧 Project Status

> Currently under development.

EduPond is being developed as a portfolio project to demonstrate
full-stack web development, REST API design, relational database
design, authentication, role-based authorization, and modern frontend
development.

---

## 👥 User Roles

### Admin
- Manage users
- Manage course categories
- Review instructor course proposals
- Monitor student course demand
- Publish and manage courses

### Instructor
- Create and manage courses
- Build course sections and lessons
- Submit courses for review
- View student course demand
- Submit course proposals

### Student
- Browse courses
- Enroll in courses
- Track learning progress
- Take quizzes
- Earn certificates
- Request new courses through Ask Course
